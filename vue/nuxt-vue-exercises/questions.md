# Preguntas
## ¿Qué es un linter?
- Es una herramienta (Pluggin) que analiza el código en busca de errores, malas prácticas y problemas de estilo sin ejecutarlo

## ¿Qué es Husky?
-  Es una herramienta wu permite ejecutar scripts automáticamente antes de hacer un commit o push en Git. Se usa para pasar el linter o test antes de subir el código

## ¿Qué es la reactividad?
- Es un sistema que detecta automáticamente cuando cambia un dato y actualiza la interfaz sin necesidad de manipular el DOM manualmente

## ¿Desde dónde hay que crear todas las ramas para los desarrollos?
- Siempre se deben crean desde el `develop` en caso de existir, y en el caso de este repositorio desde el `main` 

## ¿Cuándo se puede utilizar la rama main?
- Se puede utilizar cuando el código ya este limpio, revisado y sin errores, para mostrar el producto final del proyecto, no se debe trabajar sobre ella en producción

## ¿Qué son las custom properties?
- Son variables personalizadas en CSS declaradas `--name-var` y usadas mediante `var()` 

## Diferencias entre v-if y v-show
- `v-if` elimina el elemento del DOM, al contrario de `v-show` que lo mantiene en el DOM perio lo oculta.

## ¿Cuáles son los valores de falsy?
- Los valores falsy son `false`, `0`, `-0`,`""`, `null`, `undefined`, `NaN` 

## ¿Qué es Nullish Coalescing Operator?
- Es un operador lógico `??` que permite asignar un valor por defecto a una variable si tiene valores `nullish` (`null`,`undefined`)

## ¿Para que se utiliza TypeScript?
- Para añadir tipado a JavaScript, además permite detectar eerores cuando se desarrolla el código , además hacer el código más mantenible y mejorar el autocompletado
